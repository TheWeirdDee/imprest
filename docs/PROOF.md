# Proof

The `/proof` page renders `proof/claims/*.json`, which `scripts/src/build-claims.ts`
generates from receipts and test outputs; `scripts/src/validate-evidence.ts` checks them
(including on-chain). Ledger: [CLAIM_LEDGER.md](CLAIM_LEDGER.md). Rules:
[EVIDENCE_STANDARD.md](EVIDENCE_STANDARD.md).
